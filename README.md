# 📊 Barcode Generator

A simple and efficient **Barcode Generator** built with Python. This project allows users to generate barcode images from text or numbers using the `python-barcode` library.

## ✨ Features

* 🏷️ Generate barcodes from text or numbers
* 📷 Create barcode image files
* ⚡ Fast and easy to use
* ✅ Simple command-line interface
* 🐍 Built with Python

## 📌 Requirements

* 🐍 Python 3.8 or later
* 📦 Python packages:

  * `python-barcode`
  * `Pillow`
  * `setuptools`

## 💻 Example

```text
===== Barcode Generator =====

Enter text or number to generate barcode: 123456789

✅ Barcode generated successfully!
📁 Saved as: generated_barcode.svg
```
